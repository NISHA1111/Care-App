# Phase 01 — Discover

Owner: Research Agent.

## Readiness
Inputs: input/brd.md; input/research-notes.md. Check content, revisions, assumptions and gate status before running. Phase 1 needs usable sample inputs; later phases need current human approval.

## Execution
Persona Synthesis and Competitor Analysis run in parallel. After persona.md completes, Pain Point Extraction uses persona.md + research-notes.md. Join all outputs, validate, then send to D1.

## Outputs
Write persona.md, pain-points.md, competitor-notes.md under output/phase-01/. Add owner, version, input revision, evidence references and unresolved questions to each artifact.

## Validation and handoff
Check complete content, input traceability, assumption labels and consistency. Request D1 with a manifest in run-log.md. Do not continue until the human gate is APPROVED.

## Exceptions
Missing input → stop; weak evidence → explicitly label and retain gap; contradiction → record without resolving by guess; failed validation → same owner revises; REJECT → stop and request better input. Upstream revision invalidates downstream approvals.
