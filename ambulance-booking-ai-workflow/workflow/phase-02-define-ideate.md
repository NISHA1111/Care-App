# Phase 02 — Define / Ideate

Owner: Product Ideation Agent.

## Readiness
Inputs: all Phase 1 artifacts + current APPROVED D1. Check content, revisions, assumptions and gate status before running. Phase 1 needs usable sample inputs; later phases need current human approval.

## Execution
Chain How Might We → Feature Decomposition → Concept Direction. Features must cite pain-point/HMW IDs and remain hypotheses. Validate scope and traceability, then send to D2.

## Outputs
Write hmw.md, feature-opportunities.md, concept-direction.md under output/phase-02/. Add owner, version, input revision, evidence references and unresolved questions to each artifact.

## Validation and handoff
Check complete content, input traceability, assumption labels and consistency. Request D2 with a manifest in run-log.md. Do not continue until the human gate is APPROVED.

## Exceptions
Missing input → stop; weak evidence → explicitly label and retain gap; contradiction → record without resolving by guess; failed validation → same owner revises; REJECT → stop and request better input. Upstream revision invalidates downstream approvals.
