# Phase 03 — Design

Owner: Design Agent.

## Readiness
Inputs: approved concept-direction.md; feature-opportunities.md; persona.md; pain-points.md; current APPROVED D2. Check content, revisions, assumptions and gate status before running. Phase 1 needs usable sample inputs; later phases need current human approval.

## Execution
Chain User Flow Generation → Wireframe Planning. Pause for explicit human wireframe sign-off recorded in d3-review.md before UI Spec Generation. This internal checkpoint does not replace D3. Validate all outputs, then send to D3.

## Outputs
Write user-flow.md, wireframe-plan.md, ui-spec.md under output/phase-03/. Add owner, version, input revision, evidence references and unresolved questions to each artifact.

## Validation and handoff
Check complete content, input traceability, assumption labels and consistency. Request D3 with a manifest in run-log.md. Do not continue until the human gate is APPROVED.

## Exceptions
Missing input → stop; weak evidence → explicitly label and retain gap; contradiction → record without resolving by guess; failed validation → same owner revises; REJECT → stop and request better input. Upstream revision invalidates downstream approvals.
